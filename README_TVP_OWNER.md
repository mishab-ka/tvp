# TVP Owner Dashboard Guide

## 🚗 **Overview**

The TVP Owner Dashboard is a specialized interface designed for fleet owners and vehicle operators. It provides read-only access to fleet management, financial tracking, and support services. TVP Owners can view their assigned vehicles, track financial performance, and request support without having edit permissions.

## 👥 **TVP Owner Role**

### **Permissions**

- ✅ **`cars_list`** - View fleet of assigned vehicles
- ✅ **`hissab_view`** - View financial statements and accounting
- ✅ **`support_access`** - Access support system

### **Access Level**

- **Read-Only Access**: View information only, no editing capabilities
- **Fleet Overview**: Monitor vehicle status and details
- **Financial Tracking**: View revenue, expenses, and profits
- **Support System**: Submit and track support requests

## 🚗 **Cars List Feature**

### **Fleet Overview**

- **Vehicle Count**: Total number of assigned vehicles
- **Status Overview**: Active, maintenance, inactive vehicles
- **Quick Actions**: Filter and export capabilities

### **Vehicle Information Displayed**

- **Plate Number**: Vehicle registration number
- **Model & Year**: Vehicle make, model, and year
- **Status**: Current operational status
- **Assigned Driver**: Driver assigned to the vehicle
- **Mileage**: Current vehicle mileage
- **Fuel Type**: Vehicle fuel type
- **Next Maintenance**: Scheduled maintenance date
- **Insurance Expiry**: Insurance expiration date

### **Vehicle Status Types**

- 🟢 **Active**: Vehicle is operational and available
- 🟠 **Maintenance**: Vehicle is under maintenance
- 🔴 **Inactive**: Vehicle is not operational

### **Available Actions**

- **View Details**: View complete vehicle information
- **Generate Report**: Export vehicle reports
- **Filter Vehicles**: Filter by status, model, etc.

## 🔧 **Troubleshooting**

### **Common Issues**

#### **Can't Access Dashboard**

- **Check Permissions**: Ensure you have TVP Owner role
- **Verify Login**: Use correct credentials
- **Contact Admin**: Request role assignment

#### **No Vehicles Showing**

- **Check Assignment**: Vehicles must be assigned to you
- **Contact Admin**: Request vehicle assignment
- **Refresh Page**: Try refreshing the dashboard

#### **Financial Data Missing**

- **Check Date Range**: Verify date filters
- **Contact Admin**: Request data access
- **Clear Cache**: Clear browser cache

#### **Support Tickets Not Loading**

- **Check Internet**: Verify internet connection
- **Refresh Page**: Try refreshing the page
- **Contact Support**: Reach out to system admin

### **Mobile Issues**

#### **Layout Problems**

- **Rotate Device**: Try landscape orientation
- **Zoom Out**: Reduce browser zoom
- **Update Browser**: Use latest browser version

#### **Touch Issues**

- **Clean Screen**: Remove screen protector
- **Restart App**: Close and reopen browser
- **Check Settings**: Verify touch settings
